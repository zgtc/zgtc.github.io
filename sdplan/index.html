Stream Deck + XL layout planner

36 keys (9×4), touch strip and 6 push-dials. Click a key or dial to edit it; drag keys to swap. Folder keys (▸) open in place, with Back in the top-left like on the device. Changes stay in this browser; use Export to keep a copy.

Profile notes

Setup notes, plugin requirements and custom-plugin ideas for this profile. Editable.

Conventions

  • Suggested frame: column 9 on every page holds Home (top), ◀ Page, Page ▶, then Save or another critical action (bottom).
  • App profiles keep Undo and Redo bottom-left, where ⌘Z sits on a keyboard.
  • Keys with a corner dot are the fixed frame and stay put on every page.
  • Give related apps shared slots — the same function on the same key across, say, two video editors or two Adobe apps — so muscle memory carries over.
  • Dial 6 is an Action Trigger: turn = previous/next page, push = page 1. Swiping the touch strip also changes pages.
  • “custom” = no default shortcut; bind one in the app first. “verify” = check against the app’s shortcut list.

Key types

  • ▸ Folder — opens a sub-layout; Back is top-left. Set Auto Exit (up to 60 s) for quick-pick folders.
  • ⇄ Two-state toggle — Hotkey Switch or Multi Action Switch.
  • ⏱ Key Logic — separate actions for press, double press and press-and-hold.
